# Report Writing Practice: Sections A–E

## Experiment Prompt — Pendulum

**Topic:** Periodic Motion

**Background:** A pendulum is a mass hanging from a fixed point that swings back and forth. The time for one full swing (back and forth) is called the period. A pendulum's period can depend on how the pendulum is built and how it is released. You are prospective clockmakers who need a pendulum that keeps steady time. Design an experiment that explores the motion of a pendulum using the materials below. You do not have to use every item.

**Materials:**

- Spool of string
- 10 metal washers
- Masking tape
- Scissors
- Meterstick
- Protractor
- Stopwatch
- Calculator
- Table with an edge
