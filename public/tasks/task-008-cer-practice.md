# Full CER Practice: Effect of Drop Height on Bounce Height

## Experiment Summary

A team investigated how **drop height** affects the **bounce height** of a rubber ball. The ball was dropped from three different heights and allowed to bounce freely. Each height was tested five times under identical conditions (same ball, same surface, same drop technique).

**IV:** Drop Height (cm) &nbsp;&nbsp; **DV:** Bounce Height (cm)  
**Controlled Variables:** Same rubber ball, same tile floor, same drop technique, same measurer

**Hypothesis:** If drop height increases, then bounce height will increase because a greater drop height gives the ball more gravitational potential energy, which is partially converted into elastic potential energy on impact and then back into kinetic energy on the rebound.
